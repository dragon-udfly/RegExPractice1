# Python Regular Expressions Practice (RegExPractice1)

A structured collection of Python scripts dedicated to practicing, testing, and experimenting with regular expressions (RegEx) for text searching, pattern matching, and string manipulation.

---

## 📂 Repository Structure

```text
RegExPractice1/
│
├── expressions1.py     # Core regular expression pattern definitions and matching experiments
├── script1.py          # Introductory RegEx pattern matching script
├── script2.py          # Secondary pattern searching and filtering logic
├── script3.py          # Advanced string manipulation and regex operations
├── script4.py          # Experimental text pattern parsing routine
└── script5.py          # Supplementary expression validation script
```

## 🚀 Key Topics & Concepts Covered
1. Python re Module: Leveraging Python's built-in regular expression library for pattern searching.

2. Pattern Matching: Constructing regex patterns, matching sequences, and extracting specific substrings from text.

3. Text Processing: Automating validation and pattern extraction tasks across multiple modular scripts (script1.py through script5.py).

## 💻 Getting Started & Execution
Ensure you have Python 3 installed on your system.

🖥️ Windows & Linux (Terminal / Command Prompt)
Clone the repository:

```Bash
git clone [https://github.com/dragon-udfly/RegExPractice1.git](https://github.com/dragon-udfly/RegExPractice1.git)
```
Navigate into the directory:

```Bash
cd RegExPractice1
```
Run any script using Python:

```Bash
python expressions1.py
python script1.py
```
